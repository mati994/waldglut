# Waldglut 🌱

Ein gemütliches, browserbasiertes Idle-Clicker-Experiment: Licht sammeln, einen dunklen Wald erwecken und magische Wesen entdecken.

## Spielen

Nach Aktivierung von GitHub Pages unter **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** läuft das Spiel unter:

https://mati994.github.io/waldglut/

Die veröffentlichte Spielversion liegt in [index.html](index.html).

## Aktueller Stand

- **0.3 (in Entwicklung):** Waldchronik als zweite Ansicht, Glühwürmchen-Sammlung und Evolutionen für Lichtproduzenten.
- **0.2.1:** vorheriger spielbarer Stand, gesichert unter [archive/waldglut-0.2.1.html](archive/waldglut-0.2.1.html).

## Achtung: Spielstand

Spielstände liegen lokal im Browser (Local Storage) und sind **nicht** mit GitHub verbunden. Der Umzug von einer heruntergeladenen HTML-Datei zu einer eigenen Pages-Webadresse kann eine neue Browser-Datenablage bedeuten. Deshalb den Spielstand vor dem Wechsel in der alten Version **exportieren** und auf der neuen Webseite **importieren**. Nicht auf demselben Gerät zwischen verschiedenen Dateien/Adressen auf eine automatische Übernahme vertrauen.

## Arbeitsweise

`main` ist die öffentlich sichtbare Version. Neue Experimente bitte auf separaten Branches oder nach einem vorherigen lokalen Test entwickeln. Vor jeder größeren Änderung den Spielstand-Import sowie Klicks, Käufe, automatische Produktion und Chronik-Freischaltungen überprüfen. Versionsnummer und Änderungen dokumentieren.
